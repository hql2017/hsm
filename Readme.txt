20260323:
1、计算电控制脉宽与光脉宽关系：来源20260320-电压与脉宽测试记录
LS_set_us:目标光脉宽
	LS_control_us:电脉宽
    LS_delay_us:滞回延迟时间
	LS_off_t_us:LS_off_t_us=(V-300)/25;//关断后延迟时间（影响测量光脉宽）
	LS_delay_us=8；//8us参考20260320-电压与脉宽测试记录	
	LS_control_us=LS_set_us-LS_delay_us-LS_off_t_us*0.5;
	例：LS_seshezhit_us=120us;LS_control_us=112us.
